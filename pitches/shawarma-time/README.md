# Shawarma Time, Lalor: website concept

A one-page website concept for Shawarma Time, the Syrian shawarma shop at
379 High Street, Lalor VIC 3075, prepared to pitch to the owner.

- `index.html` is the standalone site: one file, no build step. Open it in a
  browser or serve it from any static host.
- `artifact.html` is the same page in the body-only form used for Claude
  artifacts.
- `favicon.svg` is the site icon.

Everything the page says about the business sits in the data block near the
bottom of the file (`SHOP`, `HOURS`, `MENU`, `QUOTES`, `RATINGS`). The facts
come from the shop's public delivery listings, Curateria and its socials as of
October 2026. Before launch, confirm with the owner:

- counter prices (the menu shows Uber Eats app prices),
- trading hours, including Tuesday, which no listing shows,
- halal certification, dine-in, and whether the pickles are imported,
- that the review quotes still appear on the live listings.

The page is marked as a concept and asks search engines not to index it.
